How it works

Each puzzle becomes a factor graph: variables Xi with domains, and factors fj(x) ∈ {0, 1}. A complete assignment solves the puzzle when every factor is satisfied:

weight(x) = f1(x) · f2(x) · … · fm(x) = 1

A 9×9 Sudoku has 81 variables and 810 binary “≠” factors. The solver works up an algorithm ladder, adding one technique at each step:

bt naive backtracking fc + forward checking mrv + minimum remaining values lcv + least constraining value mac arc consistency (AC-3) mac+ + hidden singles dpll CNF + DPLL

What each technique buys

1000 rated puzzles, 250 per difficulty bucket, 10 s limit per run. The solvers are pure Python, so the times compare techniques rather than measure raw speed.
